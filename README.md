# ituzovlab-alice

Навык для Алисы, который отвечает через нормальные модели: Claude, GPT, DeepSeek, Gemini, Grok. Запросы идут через Timeweb AI Gateway, а сам навык крутится на Timeweb App Platform: сервер не нужно настраивать руками, достаточно подключить этот репозиторий.

Что отвечает навык с Grok (реальные ответы, реплики «Секунду, думаю» и «дальше» убраны):

```
> Как сделать коктейль Май Тай?
< Май Тай делается так: в шейкере со льдом смешай шестьдесят миллилитров светлого рома, тридцать сока лайма, пятнадцать апельсинового ликёра и пятнадцать миндального сиропа оржа. Хорошо встряхни, перелей в бокал со льдом и сверху аккуратно налей немного тёмного рома. Укрась мятой и долькой лайма.

> Проведи код-ревью как строгий тимлид: я назвал переменную data2
< data2 это не имя, а капитуляция. Из названия не ясно, что внутри, откуда взялось и чем отличается от data. Переименуй по смыслу, иначе на ревью не пропущу.
```

Навык помнит последние 20 реплик разговора. Если модель не успевает ответить за три секунды (столько Алиса ждёт навык), он просит сказать «дальше» и отдаёт ответ, когда тот будет готов.

## Что понадобится

Аккаунт в Timeweb Cloud и аккаунт Яндекса, к которому привязана колонка.

## Установка

### 1. Ключ AI Gateway

В панели Timeweb Cloud откройте ИИ-сервисы → AI Gateway → API-ключи и создайте ключ. Он показывается один раз, сохраните его. На ключ можно поставить лимит токенов, я бы поставил.

### 2. Деплой на App Platform

App Platform → Создать → «Подключите git-репозиторий по URL», ссылка:

```
https://github.com/ituzov/ituzovlab-alice.git
```

Фреймворк Express и команда запуска `node server.js` подтянутся сами, Node.js подойдёт 22 или 24. Минимальной конфигурации (1 CPU, 1 ГБ) навыку хватает, на момент написания она стоила 510 ₽ в месяц с почасовой оплатой.

В расширенных настройках добавьте переменные. Выпадающий список там показывает только глобальные переменные, поэтому нажмите «Добавить». Весь список можно вставить разом через ⌘+V в поле «Название»:

```
API_KEY=ключ из первого шага
BASE_URL=https://api.timeweb.ai/v1
MODEL=xai/grok-4.7
REASONING_EFFORT=low
```

`MODEL` задаёт модель, которая будет отвечать. По умолчанию это Grok, потому что он весёлый. `REASONING_EFFORT=low` просит модель меньше думать перед ответом, с ним Grok отвечает быстрее. Как выбрать другую модель, написано ниже в разделе «Модели».

Путь проверки состояния, тоже в расширенных настройках: `/health`. После деплоя откройте выданный домен в браузере, там должно быть `ok`.

У репозитория, подключённого по ссылке, нет автодеплоя. Если хотите, чтобы изменения выкатывались сами после `git push`, сделайте форк и подключите его через GitHub.

### 3. Навык в Яндекс Диалогах

На [dialogs.yandex.ru/developer](https://dialogs.yandex.ru/developer) создайте навык в Алисе. В поле Webhook URL вставьте домен с App Platform, тип доступа выберите «Приватный». Название лучше взять необычное: у меня колонка сначала открывала чужой навык с похожим именем.

Сохраните и проверьте на вкладке «Тестирование». Там же в запросе будет `skill_id`. Добавьте его в переменные App Platform как `ALICE_SKILL_ID` и передеплойте, тогда сервер будет отвечать только вашему навыку.

Потом отправьте навык на модерацию. Приватные проверяются автоматически, у меня это заняло пару минут. После публикации скажите колонке «Алиса, запусти навык …».

## Команды

Внутри навыка можно говорить:

- «дальше», если навык попросил подождать;
- «хватит», чтобы выйти.

## Модели

Модель задаётся переменной `MODEL`. Чтобы сменить её, найдите ID нужной модели и вставьте его в `MODEL` в настройках приложения на App Platform, потом передеплойте.

ID удобнее всего смотреть в панели: AI Gateway → вкладка «Подключение», выберите модель, и её ID будет в примере кода. Второй способ: запросить список со своим ключом.

```bash
curl https://api.timeweb.ai/v1/models -H "Authorization: Bearer ВАШ_КЛЮЧ"
```

Для голоса важнее всего скорость, потому что Алиса ждёт ответ около трёх секунд. Grok с `REASONING_EFFORT=low` отвечает за 2–3,5 секунды, поэтому, как видно в примере выше, «дальше» приходится говорить почти каждый раз. Если это раздражает, возьмите модель побыстрее: в моих замерах `deepseek/deepseek-v4-flash` и `yandex/aliceai-llm-latest` (собственная модель Яндекса) отвечали примерно за 1–1,5 секунды, `anthropic/claude-haiku-4-5` за 2–3 секунды. Цифры сильно плавают, так что это ориентир, а не бенчмарк.

`REASONING_EFFORT` понимают не все модели. Если после смены модели навык отвечает «Не получилось достучаться до модели», уберите эту переменную.

## Характер ассистента

По умолчанию навык ведёт себя как обычный помощник: отвечает коротко, без списков и эмодзи, потому что текст зачитывается вслух. Инструкция лежит в `config.js`, а заменить её можно переменной `SYSTEM_PROMPT`, не трогая код: добавьте её в настройках приложения и передеплойте.

```
SYSTEM_PROMPT=Ты вечно недовольный кот. Отвечай ворчливо, одной-двумя фразами, по-русски. Без списков и эмодзи, текст читается вслух.
```

Писать только одной строкой: перевод строки в переменную окружения не вставить. Про то, что ответы зачитываются вслух, в своём промпте лучше упомянуть, иначе модель начнёт выдавать списки и разметку.

## Как устроен код

- `server.js` принимает запросы от Алисы;
- `alice.js` решает, что ответить: выход, память разговора, ожидание модели;
- `llm.js` делает запрос к модели;
- `config.js` хранит настройки и инструкцию для модели по умолчанию.

Память разговора хранится в процессе, без базы. Она сбрасывается, когда вы выходите из навыка, когда Алиса сама закрывает его после долгой паузы и при каждом новом деплое. Сколько реплик помнить, настраивается в `config.js` (`maxHistory`).

## Локальный запуск

```bash
git clone https://github.com/ituzov/ituzovlab-alice
cd ituzovlab-alice
npm install
cp .env.example .env
npm run dev
```

Алисе нужен публичный HTTPS-адрес, поэтому для локальной разработки порт 3000 придётся пробросить туннелем, например через [tuna](https://tuna.am).

Вместо Timeweb подойдёт любой OpenAI-совместимый API, например OpenRouter: поменяйте `BASE_URL`, ключ и ID модели.
